# TwitchMusic

Автор: **Sadako**. Windows-приложение для музыкальных заказов за баллы Twitch.

Готовые сборки и changelog на русском и английском: [Releases](https://github.com/stafford812/Twitch_yyyuma/releases).

Начиная с RC9 основной вариант — **TwitchMusic-Setup.exe**. Закройте старую копию через Exit в трее перед установкой. Python и права администратора не требуются. Настройки и очередь сохраняются.

Обновления скачиваются из GitHub отдельными компонентами; неизменившиеся библиотеки повторно не загружаются. Установка выполняется после подтверждения или выбранного выхода после стрима. Удаление доступно через параметры Windows; личные данные сохраняются для переустановки.

Windows может показать «Неизвестный издатель»: сборки не имеют сертификата Authenticode. Подпись манифеста обновлений не заменяет сертификат Windows. Отключать защиту не нужно.
